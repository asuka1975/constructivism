# 構成カタログ：学術・教育系

出典：調査レポート 3.2「学術・教育系」。各ジャンルを「適用条件／骨子／メッセージの位置／目安分量／アンチパターン／日本語の慣習」の6項目に統一して転記した。レポートに記載のない項目は「レポートに記載なし」と明記し、レポートの他章（第2章の決定木・選択マトリクス、第4章の文体の既定）から補える場合のみその旨を付して補った。レポートの根拠は「適用条件」の補足として残した。

分量の目安はレポートの経験則で、一次情報で規定されている数値はその旨を明記している。文体の既定（第4章）：論文・リファレンス・仕様書・ADR は常体、それ以外は敬体。

## 学術論文（IMRaD）

- **適用条件**：レポート 3.2 に記載なし。第2章の決定木では「検証する」→ 学術論文（IMRaD、Abstract で結論先出し）。選択マトリクスでは読者「研究者・モジュール読み」、メッセージ種別「主張と証拠」に対応し、選択理由は「定位置で情報を拾える」。
  - 根拠：Sollaci & Pereira（2004, *J Med Libr Assoc* 92(3):364–367）によれば、IMRaD は調査対象誌で1940年代に使われ始め、過半数に採用されたのは1970年代になってからで、「モジュール読み」を容易にする（"The IMRAD structure facilitates modular reading"）。木下も、著者抄録で結論・研究の目的・研究法を明示し、序論は読者を最短経路で本論へ導くよう求めている。
- **骨子**：表題 → 要旨（背景・目的・方法・結果・結論）→ 序論（背景→未解決の問題→目的）→ 方法 → 結果 → 考察（主要な知見→先行研究との比較→限界→意義）→ 結論 → 謝辞 → 参考文献
- **メッセージの位置**：表題と要旨で結論を先に示し、本文は検証の順に積み上げる。
- **目安分量**：レポートに記載なし。
- **アンチパターン**：結果と考察を混同する、序論が長い研究史になる。
- **日本語の慣習**：常体（である調）。投稿先学会の投稿規定が最優先（Q0）。

## 教科書・教材の章

- **適用条件**：レポート 3.2 に記載なし。第2章の決定木では「学ぶ」のうち「体系的知識」→ 教材の章。選択マトリクスでは読者「学生・通読」、メッセージ種別「教育」に対応し、選択理由は「教授事象の順序に沿う」。
  - 根拠：Gagné の9教授事象（注意喚起／学習目標の提示／既習事項の想起／内容の提示／学習の指針／練習の機会／フィードバック／評価／保持と転移の促進）の順序に対応させた。原典は Gagné『The Conditions of Learning』（初版1965年）。
- **骨子**：章の導入（なぜ学ぶか・問いかけ）→ 学習目標 → 前提の確認（既習事項）→ 本文（概念→例→図解の繰り返し）→ 例題 → 演習問題 → まとめ → 発展・次章への接続
- **メッセージの位置**：レポート 3.2 に記載なし。第2章の決定木 Q2「学習順序に意味がある → 冒頭は完成像と学習目標、本論は積み上げ」が該当する。
- **目安分量**：レポートに記載なし。
- **アンチパターン**：レポートに記載なし。
- **日本語の慣習**：レポートに記載なし。文体の既定は敬体（第4章）。
